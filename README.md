# Kiutra wiring log

The wiring of the Schuster Lab kiutra L-Type Rapid cryostat, drawn stage by stage, with a version history.

- **View:** https://schusterlab.github.io/kiutra-wiring-log/
- **Edit:** open the page, click *Sign in to edit*, and paste a fine-grained GitHub token with Contents read and write access to this repository. Each saved version is a commit to `data/log.json`.
- **Wallpaper:** every push rebuilds the site and takes a dark-mode 1920 × 1080 screenshot, `wallpaper.png`, which the kiutra PC downloads as its desktop background.

`files/` holds the vendor datasheets the diagram links to. Version 1 is the vendor wiring drawings (DC tree J001245 of 2026-10-16, RF tree J001245 of 2026-10-21); it is built into `index.html`, so `data/log.json` holds only later versions.
